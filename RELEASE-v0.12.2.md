# Norwood.ma v0.12.2

## Developer continuity documentation

This release adds `EVENT-SUBMISSION-SYSTEM.md`, a permanent technical/operational reference describing the community event submission system introduced in v0.12.0.

It documents the Google Form and response Sheet architecture, moderation fields and statuses, Apps Script setup/trigger behavior, no-file-upload policy, public/private data boundary, verification expectations, and the not-yet-implemented authenticated bridge from Approved submissions into `events.json`.

Future releases must include this file and update it whenever this workflow changes.
