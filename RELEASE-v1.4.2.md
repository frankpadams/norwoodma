# Norwood.ma v1.4.2 — destination-specific Townie sharing

**Release date:** October 27, 2026

## User-facing changes

- Facebook, X, Instagram, and Text now open the selected destination directly instead of routing through the generic system share sheet.
- Facebook’s profile/group choice opens Facebook’s composer with the caption and quiz link prefilled. The score image is copied for pasting when clipboard image support is available, or downloaded for attaching.
- Added a separate More apps option for system sharing. When supported, it shares the score image, caption, and quiz link together.
- Corrected the quiz’s final answer order and related progress labels.

## Sharing limitation

Direct website composers for Facebook, X, and Instagram do not accept a client-generated image attachment through their share URLs. The score graphic is copied or downloaded for the user to add to the post. The More apps and Copy options include the graphic directly when the browser supports it.
