# Norwood.ma v1.2.0 — ALPR camera map layer

Released October 26, 2026.

- Added an optional “ALPR cameras” overlay to Explore Norwood by Map; it starts off and loads public vector tiles only when selected.
- Added hover/focus and tap-accessible help expanding ALPR to “Automated license plate readers (AI-enabled surveillance devices).”
- Added available camera metadata and OpenStreetMap record links to marker popups.
- Documented the community-mapped data source and incomplete-coverage limitation.

Known limitation: the feed reflects community-mapped OpenStreetMap records and may omit cameras or contain stale/incorrect locations. The map does not claim to show every ALPR device.
