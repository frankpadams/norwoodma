# v2.3.4 — Expandable daily Recreation listings

Released November 26, 2026.

- Adds recurring, multi-session Norwood Recreation classes and programs to the combined default event calendar.
- Shows one expandable Recreation entry per date, with the individual scheduled classes, times, locations, details, and registration links inside.
- Leaves one-time events as individual listings and keeps calendar selection available as an optional way to narrow or subscribe to calendars.
