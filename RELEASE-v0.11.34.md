# Norwood.ma v0.11.34

- Transit station and schedule controls changed from large cards to compact peer links.
- Norwood Depot, Norwood Central, and Windsor Gardens now appear as equal station links, followed by the Franklin/Foxboro full-line schedule.
- 34E full route schedule remains a compact route-level link.
- Service alerts are collapsed by default into a small expandable summary.
- Transit map is constrained in width and height.
- Mouse-wheel map zoom is disabled so desktop page scrolling is not trapped.
- Mobile map dragging/touch zoom is disabled so vertical swipes continue to scroll the page; map zoom controls remain available.
