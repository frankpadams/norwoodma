# Norwood.ma v1.3.0 — live MBTA map layer

Released October 26, 2026.

- Added an optional, off-by-default live MBTA layer to Explore Norwood by Map for 34E buses, Franklin/Foxboro Line trains, route paths, and Norwood-area stops.
- Vehicle locations refresh every 30 seconds while the layer is enabled; popups show direction, reported status, and update time.
- Grouped the town boundary, voting precinct overlay, school and voting district reference links, ALPR camera layer, and live MBTA layer under one “More map layers & options” pulldown.
- Added the Town’s voting district map PDF alongside the address lookup links.

Known limitation: live vehicle markers appear only when MBTA reports a location; the layer uses the public MBTA V3 API and does not replace the official school assignment or voting address lookup tools.
