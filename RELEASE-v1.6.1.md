# v1.6.1 — Community-first event calendar

Released November 6, 2026.

- Establishes and applies the permanent nine-tier daily event ranking across the homepage and full community calendar.
- Includes public Norwood municipal board and committee meetings and public religious events; religious events sort last.
- Uses starting time as the tie-breaker within each priority, placing untimed events after timed events.
- Keeps event times inline where space allows, uses compact lowercase times such as “9am,” and uses abbreviated month/day dates such as “Jan 24.”
- Moves event classification and sorting to the shared agenda comparator so generated and newly refreshed listings use the same policy.
