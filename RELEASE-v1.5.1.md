# v1.5.1 — Compact map category selector

Released November 4, 2026.

Replaced the large map category buttons with compact text rows and checkboxes, matching the Trails selector. Parks, playgrounds and athletic fields share one filter; multi-category filtering and existing map layers remain available. On mobile, the map now stacks below the layer list instead of being squeezed into a narrow column. Clearing all selected categories returns to the full map.

This is a small map-page usability refinement. No map data or filtering rules changed.
