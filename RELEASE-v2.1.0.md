# Norwood.ma v2.1.0

Released November 22, 2026.

- Adds an Accessibility group to Explore Norwood by Map with separate overlays for wheelchair information at mapped places and tagged accessible paths/crossing details.
- Loads community-contributed OpenStreetMap data when an overlay is enabled through a cacheable same-origin PHP relay. Shows layer-specific symbols, source links, status, and coverage notes in the existing map legend and layer information UI.
- Accessibility tags are incomplete and may not reflect current conditions. Missing map information does not indicate that a place or route is inaccessible.
