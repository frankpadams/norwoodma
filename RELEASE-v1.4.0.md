# Norwood.ma v1.4.0 — How Townie Are You?

**Release date:** October 26, 2026

## User-facing changes

- Added **How Townie Are You?**, a quiz page separate from Norwood Trivia.
- Added 12 Norwood knowledge questions and 13 Have You Ever prompts. Correct answers and “Yes” responses earn Townie points.
- Randomized multiple-choice option order and added an accessible dropdown matching interaction for the McDonough question.
- Added the new page to the sitemap; it is not linked from other site pages yet.

## Notes

- The quiz is an unofficial, just-for-fun feature. It does not collect or store scores.
- The existing Norwood Trivia page and map were not changed.
