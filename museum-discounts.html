WAYS TO SAVE

Museum passes & attraction discounts

Before paying full price, check whether the library or another program can get you in free or at a discount. Programs and availability change, so use the official links below to confirm before visiting.

START LOCAL

Morrill Memorial Library museum passes

The library has an online reservation system that shows passes by museum or by date, including live Available / Limited / Unavailable status. Norwood.ma does not label a pass “available now” unless that live system says so.

🎟️
Check current library passesMorrill Memorial Library · live reservation system
 📅
Find a pass by dateSee what is available for the day you want to go

The library’s 2026 reservation system has included passes for destinations such as the Museum of Science, New England Aquarium, Roger Williams Park Zoo, Zoo New England, USS Constitution Museum, Massachusetts State Parks, Trustees properties and Maplewood’s indoor/outdoor playground. The live library system is authoritative for today’s inventory, benefits and availability.
